# Contributing

Keep Phase 1 changes small and observable. Add tests when changing authentication, process invocation, filesystem boundaries or persistence. Run backend pytest and frontend build before proposing changes. Never add shell execution endpoints, unauthenticated controls, root requirements or silent engine/driver installation. Do not commit model weights, secrets or machine-specific paths. Document engine provenance and license separately from this project's proposed MIT license. Publication and external contribution acceptance are pending the owner's license decision.
